# Governance

Indie Keyword Finder uses a maintainer-led model.

The maintainer is responsible for:

- product scope and release decisions;
- repository access and contributor roles;
- code, privacy, security, and Chrome Web Store compliance;
- accepting or declining issues and pull requests;
- publishing releases and handling urgent fixes.

Contributors earn broader responsibility through sustained, constructive work,
sound judgment, and respect for the Code of Conduct. Maintainer access may be
changed or removed to protect users, credentials, release integrity, or the
health of the project.

Architecture and product decisions should be recorded in issues or decision
notes. Chrome publisher credentials, verification data, recovery material, and
private incident information must remain outside the public repository.
