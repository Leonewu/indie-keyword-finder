# Code of Conduct

Indie Keyword Finder adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its community Code of Conduct.

Everyone participating in project spaces is expected to create a welcoming,
inclusive, harassment-free environment; use respectful language; accept
constructive feedback; focus on what is best for the community; and show
empathy toward other participants.

Examples of unacceptable behavior include harassment, sexualized attention,
trolling, insulting or derogatory comments, threats, publishing another
person's private information, or conduct that would reasonably be considered
inappropriate in a professional setting.

## Enforcement

For a private report, use the repository's GitHub private vulnerability
reporting channel and prefix the title with `Conduct:`. Reports will be handled
as privately as reasonably possible. Maintainers may remove, edit, or reject
contributions and may temporarily or permanently restrict participation when
behavior violates this policy.

The complete Contributor Covenant 2.1 text and enforcement guidelines at the
link above govern if this summary is incomplete.
